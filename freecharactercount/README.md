# Free Character Count

A modern, free online character and word counter built with Next.js.

## Features

- Live character, word, sentence, paragraph, and space counts
- Characters with and without spaces
- Reading and speaking time, unique words, sentence stats, Flesch–Kincaid grade
- Word density (English stopwords filtered)
- Case tools, copy, and clear
- Writing suggestions
- Social and SEO character limit meters

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
