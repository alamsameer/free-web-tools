# Stage 1 — Research

## Goal

Understand the reference product before writing code.

## What we use

- Live reference URL (example used: `https://www.charactercountonline.com/`)
- Browser / `WebFetch` / page inspection
- Optional related pages (e.g. `/word-counter/`)
- Competitor gaps for modern upgrades

## How

1. Open the reference site.
2. List every visible feature:
   - Inputs (textarea, paste, upload, etc.)
   - Live outputs / metrics
   - Tools / converters / buttons
   - Settings / menus
   - Mobile behavior
3. Note what updates live vs on submit.
4. Separate:
   - **Must-match core** (same job as reference)
   - **Modern upgrades** (better UX the reference lacks)
   - **Out of scope for v1**
5. Write a short feature inventory before scaffolding.

## Output of this stage

- Tool name / brand
- Feature checklist for v1
- Explicit exclusions
- UX notes (center-aligned, live updates, etc.)
